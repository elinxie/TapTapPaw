TapTapPaw Web Sync

Feeds time, weather and (manual) music info to the board over USB from this page. Chrome or Edge on desktop. Quit the TapTapPaw desktop app first: only one program can hold the serial port.

Connection

Status: disconnected
The board usually reboots once when the port opens; sending starts after a short wait.

Widget builder (layout for the board)

Place widgets on the 240x320 screen, add pages you swipe between, then press Send to board. Nothing is compiled: the board reads the layout. Needs firmware with the layout engine (PR #7 or later).
What the board can and cannot do: it draws a fixed set of widget types from data it already gets (time, weather, music, system bars, taps). No images, web content or custom fonts yet. The analog clock (90x90) and the cat (200x132) have fixed sizes. Fonts here are close to the board's, not identical. The preview uses this page's time, weather and typed music when it has them, sample values otherwise. If a layout ever misbehaves, hold BOOT while powering the board to start without it, or use Settings > More > Reset layout.

Sounds (your own sounds for the board)

Pick any audio file (mp3, wav, m4a, ogg...). This page cuts it to at most 5 seconds, converts it to mono 16-bit audio the board can play, lets you listen, and sends it to a sound slot. Your copy is stored next to the original sound, never over it: Reset sound deletes only your copy and the original (or the built-in beep) comes back. The storage is shared with pictures. Needs firmware feature level 3.

The board plays WAV only: the page does the conversion in your browser, nothing is uploaded anywhere else. Sounds longer than the free space allows are refused before sending. A custom sound for the weather slots replaces the original every time the weather changes; for Pet tap, Pomodoro end, Reminder and the button sounds it replaces the built-in beep. Button sounds: pick a widget of type Button in the builder and set Press sound.

Time and battery

Sent every second: this computer's local time. Battery level and charging state come from the browser Battery API when Chrome offers it: n/a

While signed in and connected, the board shows what your Spotify account is playing on any device (phone, speaker, desktop) and overwrites the typed title/artist. Only Spotify: other players are not visible to a web page.

Device settings and mood

Settings are only sent when you press Apply, so the board keeps its own saved values otherwise.

Key mapping

Sets what each physical key gesture does on the board (stored on the board). Key events are always reported to the page regardless.

Board WiFi (standalone mode)

Needs the WiFi firmware build (esp32dev_wifi). Lets the board show time and weather with only USB power, no computer. It uses the lat/lon from the Weather section. The password is stored unencrypted in the board's flash and is never saved by this page. 2.4 GHz WPA2/WPA3-personal only: company (802.1X) networks and sign-in-page networks will not work. The board's reply shows in the log.

What a web page cannot do

  • No system-wide keyboard or mouse activity. A browser only sees input inside its own tab, so the paw does not follow your typing in other apps. Use the desktop app for that.
  • No CPU or memory load. The browser does not expose them, so the page sends 0 and those chart bars stay empty.
  • No system-wide now-playing info. The Media Session API only covers audio this page plays itself, so music is typed in above.
  • The tab must stay open. Timers run in a worker so a background tab keeps sending, but closing the tab or the laptop sleeping stops it.
  • Physical key events from the board are shown in the log below; the page cannot turn them into computer keystrokes.
